# Social menu
The global Social drawer has Brawlers, Messages and Requests. Friends, Online and Offline are mutually exclusive sections. The avatar opens the public profile; the row and unread badge open the private conversation; the last slot is the options button. The drawer uses the shared palette and a native modal dialog, with the navigation's 850px mobile breakpoint.

Direct messaging is available between all visible, registered accounts regardless of friendship or online status. Message blocks apply to private messaging in both directions, not to unrelated lobby/friendship features. Reports use the existing administrator feedback queue and include only the reporter's explicit description and target account. Existing server-side account visibility restrictions remain enforced.

Apply migration `0022_social_messages.sql` to an isolated preview D1 database before testing. The API uses authenticated account IDs, same-origin writes, rate limits, bounded history pages, server-checked block/visibility rules and a client-generated idempotency key. The existing authenticated social socket sends targeted message.changed cache invalidation only, without reloading the full directory for ordinary messages; message content is fetched over the authorized endpoint. Unread counts are recipient-specific and read updates are bounded by the viewed message ID. Account changes remount the provider to clear private state.

Verification: `npm run test:social`, `npm run build`, `npm run test:visual` including the new guest drawer layout test, and two independent registered-account browser sessions on an isolated preview. Exercise offline delivery, blocking/unblocking, reconnect, unread totals, older history, failed-send retry, report submission, profile navigation and lobby invite acceptance. No production migration should be run as part of this workshop.

## Automatic presence
All connected accounts remain in Friends or Online; disconnected accounts are grey and appear in Friends or Offline. Presence is green while active, yellow after five minutes without trusted browser input, and blue during an active game. Lobby text is retained while away. Casual, Ranked and Training are derived from authoritative lobby membership and current series records (including Training checkpoints); no manual controls or new migration are introduced. A connected account is active if any connected tab is active. The socket stores activity in hibernation attachments, with throttled updates; automatic inactivity and cross-shard game transitions are reflected by the existing snapshot refresh (20 seconds with the drawer open, 60 seconds otherwise). Preview checks should include all three modes, inactive lobbies, multi-tab activity, reconnect and completion/leave.
